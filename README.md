# Hi, I'm Ivan

### Junior Frontend Developer (Angular)
I'm a frontend developer in training, focused on building modern and responsive web applications.

After 15 years of working in the warehouse industry (it was a great career!), I decided to change my path and move into software development. I spent a couple of years studying frontend development and building my own projects to turn theory into practical skills.

I especially enjoy creating user interfaces and working on application logic with JavaScript and TypeScript. My main focus is Angular, but I also work with HTML, CSS/SCSS, REST APIs, RxJS and Git.
